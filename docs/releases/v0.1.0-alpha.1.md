# Lumina Optimized 0.1.0-alpha.1

Primera alpha para Minecraft Java 26.3 con Fabric Loader 0.19.5 y Java 25 de 64 bits.

## Base incluida

- Sodium 0.9.2+mc26.3.
- Lithium 0.26.2+mc26.3.
- FerriteCore 9.0.0-fabric.
- ImmediatelyFast 1.17.1+26.3.
- La variante Shaders añade Iris 1.11.7+mc26.3 desde la misma base. No incluye shader packs ni activa shaders por defecto.

Versiones fijadas con packwiz por ID de publicación y hash. Se conservan los ajustes predeterminados, sin overrides de configuración. Sodium incluye los módulos de Fabric API necesarios; Fabric Loader incluye MixinExtras 0.5.5. No se añade Fabric API completo ni copias externas de esas dependencias.

Entity Culling, More Culling, Dynamic FPS y C2ME quedan para evaluaciones posteriores.

## Validaciones realizadas

- Sintaxis de scripts Python y archivos TOML/JSON utilizados.
- Integridad de índices y archivos de packwiz.
- Hashes y tamaños de los JAR descargados y del Loader.
- Metadatos de compatibilidad, dependencias transitivas y módulos integrados en los JAR; conflictos declarados del conjunto.
- Exportación de ambas variantes mediante packwiz.
- Integridad ZIP, contenido, versiones, lados cliente/servidor, URLs, tamaños y hashes de ambos manifiestos `.mrpack`.

Estas son comprobaciones estáticas: no equivalen a ejecutar el resolvedor de Fabric o probar Minecraft.

## Pruebas pendientes

- Importación de ambos paquetes en un launcher, en instancias limpias.
- Arranque de Minecraft, apertura/guardado de mundos y conexión a servidor.
- Estabilidad, carga de chunks, cambios de dimensión y revisión visual en macOS, Windows y Linux.
- Iris sin shaders y con un shader concreto, fijando versión y ajustes.
- Rendimiento: FPS promedio, percentiles de tiempo de fotograma, caídas de FPS, memoria, ticks y carga/generación de chunks.

El protocolo del repositorio compara vanilla, Fabric, Fabric + Sodium y Lumina con igual resolución, calidad visual y ajustes del mundo. No hay mediciones realizadas ni se promete una mejora de rendimiento. Las tres plataformas son objetivos de soporte, todavía no certificados.

## Descargas

Importa una sola variante en una instancia nueva y selecciona Java 25 nativo para tu arquitectura:

- `Lumina-Optimized-0.1.0-alpha.1-core.mrpack`: base mínima.
- `Lumina-Optimized-0.1.0-alpha.1-shaders.mrpack`: misma base con Iris opcional mediante esta variante.

Los paquetes referencian descargas de mods y requieren conexión a Internet.
