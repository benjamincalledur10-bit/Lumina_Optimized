Lumina Optimized **0.1.0-alpha.5** reconstruye la composición desde la lista nueva para **Minecraft 26.3, Java 25 y Fabric Loader 0.19.5**. Importa el único archivo adjunto en una instancia nueva de Modrinth App o Prism Launcher.

## Base incluida

- **35 mods principales + 7 bibliotecas externas = 42 JAR descargables**. Las 42 entradas objetivo están representadas; Text Placeholder API viene integrado y ZConfig es la dependencia adicional de Fast Noise.
- Sodium 0.9.2, Iris 1.11.7, Reese’s Sodium Options 2.2.5 y Sodium Extra 0.9.4; BBE activo. Iris tiene shaders apagados y LambDynamicLights comienza en Off.
- No se incluyen shader packs ni recursos adicionales. Se conservan resolución, distancias y calidad; More Culling no superpone sus ajustes de hojas a Cull Leaves. ServerCore mantiene desactivadas las alteraciones automáticas de distancias, mobcaps y comportamiento.
- ModernFix/Lithium conserva la excepción del caché de temperatura. FastQuit conserva su protección con Ixeris. C2ME y Remove Reloading Screen son publicaciones alpha.
- **142 apariciones de módulos integrados, 117 IDs distintos y 116 seleccionados estáticamente**, excluyendo los módulos del Loader. Fabric enumeró 162 IDs durante el arranque real.

[Versiones y changelog completos](https://github.com/benjamincalledur10-bit/Lumina_Optimized/blob/v0.1.0-alpha.5/docs/changelog-alpha.5.md). Alpha.1–alpha.4 y sus releases se conservan.

## Validaciones realizadas

Publicaciones Fabric 26.3, IDs/versiones, URLs oficiales, tamaños, SHA-1/SHA-512 de JAR y dependencias integradas; predicados y conflictos declarados; configuraciones, índices packwiz, inventario exacto y exportación `.mrpack`. **7 pruebas estáticas pasaron**. No se suben JAR locales al repositorio ni a la release.

El arranque aislado con Java 25 ARM64 aceptó la resolución de Fabric, creó la ventana SDL cocoa, cargó recursos y retiró el overlay de recarga. El harness lo detuvo a los 45 segundos; el código 143 corresponde a SIGTERM, no a un crash espontáneo. La limitación anterior de pantalla SDL no ocurrió.

## Limitaciones y pruebas pendientes

EMF registró creación repetida de modelos; BBE documenta limitaciones con modelos personalizados EMF/ETF. Revisar cofres, shulkers y banners durante juego. En este Mac C2ME no encontró su biblioteca matemática nativa ARM64 y desactivó esa aceleración. Los errores de autenticación/Realms del arranque usaban un token ficticio.

**Pendientes:** importación en launcher, entrada a un mundo, exploración, estabilidad de 10–15 minutos, HUD con Gnetum/ImmediatelyFast/Better Mount HUD, guardado y reapertura con FastQuit/C2ME/Ixeris, y cierre normal. Gnetum puede reducir la frecuencia de actualización del HUD. No se midieron FPS ni se comprobaron ganancias; acercarse a 200 FPS sigue siendo un objetivo.
