# Lumina Optimized 0.1.0-alpha.2

Alpha de prueba para Minecraft Java 26.3, Java 25 de 64 bits y Fabric Loader 0.19.5.

## Cambios

- Se mantienen Sodium 0.9.2, Lithium 0.26.2, FerriteCore 9.0.0 e ImmediatelyFast 1.17.1.
- Se incorporan Entity Culling 1.11.2, More Culling 1.9.0 y Better Block Entities 1.3.9, con Fabric API 0.161.0+26.3 y Cloth Config 26.3.159.
- Shaders se genera desde la misma base con Iris 1.11.7; no incluye shader packs ni activa shaders por defecto.
- C2ME 0.4.2-alpha.0.89 se añade solo a variantes experimentales.
- Se generan 16 perfiles con controles, incorporaciones aisladas, pruebas con Iris y activación experimental de BBE.

No se cambian resolución, distancias o ajustes gráficos de referencia. Entity Culling mantiene safeMode y desactiva tick culling; More Culling desactiva LOD y modos agresivos.

**BBE está incluido pero desactivado en Core/Shaders**: su renderizador puede cambiar visibilidad y tratamiento de animaciones. Los perfiles `bbe`, `bbe-shaders`, `core-bbe-enabled` y `shaders-bbe-enabled` lo activan para pruebas; su paridad visual sigue pendiente.

## Descargas

- `...-core.mrpack`: base conservadora.
- `...-shaders.mrpack`: misma base con Iris.
- `...-c2me.mrpack` y `...-c2me-shaders.mrpack`: pruebas de exploración/carga de chunks.
- `...-test-packages.zip`: los 16 perfiles. Extraer e importar un `.mrpack`, no importar el ZIP completo.
- `SHA256SUMS-0.1.0-alpha.2`: hashes de todos los paquetes individuales.

Importar en instancias nuevas con Java 25 nativo para la arquitectura del equipo. Los manifiestos requieren conexión a Internet para descargar los mods.

## Validaciones realizadas

- Versiones, IDs, hashes y tamaños de descargas; integridad de JAR y módulos anidados.
- Predicados de versiones con la API de Fabric Loader 0.19.5 y revisión de conflictos declarados.
- Opciones reales, sintaxis de configuraciones y bytes de los overrides exportados.
- Índices packwiz, contenido y hashes de los 16 `.mrpack` y del bundle.
- Nueve pruebas de composición/resolución y comprobación de aplicación del parche experimental de Sodium.
- Artefactos y reporte de alpha.1 conservados intactos. Alpha.1 no tenía mediciones de rendimiento.

La selección estática de candidatos anidados no sustituye al resolvedor completo de Fabric, la inicialización de mixins ni una ejecución de Minecraft.

## Pruebas pendientes

Importación en launcher, arranque, aceptación efectiva de configuraciones, estabilidad, paridad de geometría/animaciones/sombras y rendimiento en macOS, Windows y Linux. No hay mediciones de FPS, memoria o chunks ni se promete una mejora.

El protocolo compara controles con idénticos gráficos y mundo, y separa cada incorporación para detectar efectos e interacciones. C2ME requiere evaluar latencia visible, memoria y ticks además de generación de chunks.

## Investigación propia

Se incluye una hipótesis y un parche para comparar el presupuesto mínimo de uploads de Sodium, con flag JVM A/B. **El fork no está compilado ni distribuido en estos paquetes**; el flag solo funcionará tras compilar e instalar el parche. No hay resultados de rendimiento de esta propuesta.
