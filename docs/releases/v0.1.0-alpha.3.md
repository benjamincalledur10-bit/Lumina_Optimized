# Lumina Optimized 0.1.0-alpha.3

Pre-release de prueba para Minecraft **26.3**, Java **25 de 64 bits** y Fabric Loader **0.19.5**.

## Cambios

- Referencia alpha.2 con **Better Block Entities activado**, conservando las demás configuraciones y versiones de la base.
- Core incorpora **BadOptimizations 2.4.1**, **Structure Layout Optimizer 1.1.4+26.3-fabric** con **Resourceful Config 6.0.1**, y **Fast Noise 1.1.1+26.3** con **ZConfig 1.0.0+26.x**.
- `deduplicateShuffledTemplatePoolElementList=false`: no se activa la deduplicación que puede cambiar la distribución de estructuras para una misma semilla.
- Se prepararon 17 perfiles reproducibles desde una sola base: referencia, candidatos aislados, conjunto completo, controles de bibliotecas, Shaders con Iris 1.11.7, Gnetum con/sin ImmediatelyFast y C2ME experimental.
- Gnetum y C2ME no forman parte del Core adjunto. Gnetum puede reducir la frecuencia de actualización del HUD; su interacción con ImmediatelyFast en 26.3 permanece pendiente de comprobar.

No se cambian resolución, distancias, animaciones ni calidad visual de referencia. BBE activo conserva las limitaciones de paridad visual documentadas.

## Archivo para importar

Se adjunta únicamente **`Lumina-Optimized-0.1.0-alpha.3-core.mrpack`**. Importarlo en una instancia nueva de Modrinth App o Prism Launcher con Java 25 nativo para la arquitectura del equipo. Necesita conexión para descargar los mods.

Los otros perfiles se generan desde el repositorio con `scripts/build.py`; no se adjuntan ZIP, hashes sueltos ni paquetes experimentales a esta release.

## Validaciones realizadas

- Versiones fijadas mediante packwiz, publicaciones Fabric para 26.3, IDs, URLs, tamaños y hashes de descargas.
- Integridad de JAR y dependencias integradas recursivas; predicados reales de Fabric Loader 0.19.5, aliases y conflictos declarados en Fabric/Modrinth.
- Configuraciones y opción/ruta real de SLO; índices, manifests, overrides y hashes de los 17 `.mrpack` y del ZIP de ensayos.
- **13 pruebas estáticas** de composición y resolución; referencia alpha.2 con BBE activo conservada y paquetes anteriores intactos.

Estas comprobaciones no ejecutan el resolvedor completo de Fabric, mixins, launcher ni Minecraft. La inspección con JDK 21 no es una prueba de arranque con Java 25.

## Pruebas pendientes

**Importación, arranque, estabilidad y rendimiento en Minecraft** para macOS, Windows y Linux. También faltan paridad visual y de generación, compatibilidad efectiva con Iris, cadencia/respuesta del HUD de Gnetum con ImmediatelyFast y funcionamiento de C2ME con las bibliotecas NightConfig de ZConfig.

Comparar los perfiles con idénticos ajustes efectivos y copias del mundo según `docs/benchmarks.md`. El usuario informa mediciones anteriores de alpha.2 con BBE activo, pero sus datos crudos no se han recibido. **Todavía no hay mediciones de estos candidatos ni se afirma una mejora de FPS.**
