## Dependencias y contenido integrado

La definición packwiz usa exclusivamente URLs oficiales y SHA-512 de cada publicación. [selection.json](selection.json) conserva IDs de proyecto y versión, nombres, SHA-1/SHA-512, tamaños, etiquetas de compatibilidad, dependencias de publicación y los metadatos `fabric.mod.json` inspeccionados recursivamente. [validation.json](validation.json) registra la selección efectiva de módulos.

- **Sodium 0.8.14 + Iris 1.10.8:** Iris exige el ID de versión de Sodium `rkdTcxoT`. Reese’s Sodium Options 2.2.4 exige la versión interna `0.8.14+mc1.21.11`; Sodium Extra 0.9.4 pide esa versión o posterior y Loader ≥0.19.2. No se añade Sodium Options API.
- **BBE 1.3.4** exige Sodium ≥0.8.7. Sus notas anuncian Sodium hasta 0.8.13-beta.2: los metadatos permiten 0.8.14 y el arranque conjunto funcionó, pero el renderizado de BBE en un mundo sigue pendiente.
- **Fabric API** satisface los módulos requeridos por mods, incluido LambDynamicLights. **Cloth Config** atiende, entre otros, More Culling, FastQuit y Zoomify. **Fabric Language Kotlin/YACL** cubren Zoomify; **Forge Config API Port** cubre Remove Reloading Screen. GeckoLib se conserva como biblioteca de la composición original.
- **Fast Noise 1.0.40+1.21.11** no declara ZConfig obligatorio en el catálogo ni en su JAR, a diferencia de 26.3. Se conserva ZConfig 1.0.0+1.21.x por continuidad; ambos integran Night Config 3.8.3, resuelto una sola vez por Loader.
- **MidnightLib 1.9.2** viene dentro de Cull Leaves; coincide por SHA-512 con la publicación oficial `OeTayxh3`. **Text Placeholder API 2.8.2+1.21.10** viene en Mod Menu y está publicado también para 1.21.11 (`qxjzQ9xY`); ServerCore incluye 2.8.1 y Fabric seleccionó 2.8.2. No se descargan duplicados externos.
- **MixinExtras 0.5.5** lo proporciona Fabric Loader; prevalece sobre las copias anteriores integradas en mods y su alias anterior. No se instala otro JAR.
- **C2ME 0.3.6.0.0** funciona bajo Java 21 sin el módulo opcional integrado `c2me-opts-natives-math`, que exige Java ≥22. El archivo original no se modifica.
- Polytone recomienda **Nautilus Studio**, pero no lo requiere. Se conserva el alcance y se documenta la advertencia, sin añadirlo.

Ningún componente de la composición actual quedó sin publicación compatible. No se arrastraron mods adicionales de alpha.4, ni se sustituyeron proyectos. El Mandala de esta edición es el original de Modrinth **2.1**, no el archivo 2.6 de la variante CurseForge de 26.3.

## Retirada solicitada — 12 de octubre de 2026

**Gnetum 4.6.3+1.21.11-fabric** (`H20D00A2`) se retira del paquete 1.21.11 por petición del usuario. No es una incompatibilidad declarada ni una afirmación de mejora medida. Se eliminan únicamente su descriptor y configuración; no contenía módulos integrados y no se retiran bibliotecas compartidas. La evidencia y los artefactos anteriores se archivan localmente. La edición 26.3 conserva Gnetum.
