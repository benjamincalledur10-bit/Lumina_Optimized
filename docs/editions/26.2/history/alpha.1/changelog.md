# Lumina Optimized v26.2-alpha.1

Primera alpha independiente para **Minecraft 26.2 · Java 25 · Fabric Loader 0.19.5**, en `26.2dev`, desde la composición final de 26.3-beta.1.

- **35 mods principales + 7 bibliotecas externas + PolyTone = 43 JAR**. Se conservan todos los proyectos de mods de 26.3; archivos específicos para 26.2 y versiones fijadas con packwiz/URLs/hashes oficiales.
- Pareja **Sodium 0.9.2 + Iris 1.11.4**, comprobada contra la dependencia exacta de Modrinth y metadatos internos.
- Versiones destacadas: **BBE 1.3.7**, **Lithium 0.25.3**, **ImmediatelyFast 1.16.5**, **More Culling 1.8.1**, **ModernFix-mVUS 5.27.19-build.2**, **C2ME 0.4.2-alpha.0.60**, **ServerCore 1.5.19**, **LambDynamicLights 4.12.4**, **Sodium Extra 0.9.4**, **Reese’s 2.2.4**, **Mod Menu 20.0.3**. [Lista completa y cambios de versión](versions.md).
- Bibliotecas: **Fabric API 0.161.0+26.2**, **Cloth Config 26.2.155+fabric**, **Fabric Language Kotlin 1.14.2+kotlin.2.4.21**, **Forge Config API Port 26.2.1**, **GeckoLib 5.5.5**, **YACL 3.9.7+26.2-fabric**, **ZConfig 1.0.0+26.x**. PolyTone **26.2-6.8.6** conserva Fullbright. Text Placeholder **3.1.0-beta.1+26.2** integrado en ServerCore; sin duplicación.
- **Mandala 2.1 añadido y activado solo en Modrinth**, por petición expresa del usuario tras la primera exportación. Se conserva el ZIP oficial `Z2ajDlEE` sin modificar, su URL y SHA-1/SHA-512. No está publicado para 26.2: su formato antiguo 64 se acepta explícitamente, y se comprueba su recarga real. La apariencia queda pendiente. Para CurseForge se mantiene su omisión. Los **cuatro resource packs** quedan activos: Translations for Sodium 8.19.0, Fresh Animations 1.10.5, Fullbright UB 7.0 y Mandala 2.1.
- Conserva Lumina Event Horizon **1.3.9** y Lumina Lite **1.2.9**, instalados pero apagados. Fullbright mantiene su nombre oficial con 26.3, aunque está publicado también para 26.2.
- Se conserva Zoomify **2.16.3+26.2**, de la misma línea que la base. No se elige 2.17.0 ni se añade CatConfig. No se arrastran Language Reload/ScalableLux de 1.21.11.
- **BBE activo, shaders y luces apagados**, Entity Culling tick culling apagado/modo seguro activo, Gnetum activo/downscale apagado, resolución nativa en macOS. Configuraciones de mods idénticas a la base; verificación de claves reales y de ModernFix/Lithium repetida. ServerCore sin cambios automáticos de distancias o comportamiento. `options.txt` usa data version **4903** y cuatro recursos; acepta explícitamente solo el formato antiguo de Mandala.
- **49 referencias y 13 overrides**, hashes oficiales, dependencias recursivas, conflictos, CRC y exportación comprobados. Siete grupos estáticos superados.
- **Arranque real de 45 segundos en macOS ARM64/Java 25:** ventana/recarga terminadas y cuatro recursos, incluido Mandala, sin rechazo de metadatos; 166 IDs coincidentes con el resolvedor. SIGTERM/143 deliberado, sin mundo ni mediciones de FPS.
- EMF registra 12 avisos de recreación de modelos, también presentes en la base. Aspecto/modelos de BBE/EMF/Fresh Animations pendientes. Las notas de BBE anuncian Sodium hasta 0.9.1, aunque su predicado permite 0.9.2 y el arranque con Iris funciona. Atriles, shaders, exploración, guardado y reapertura requieren prueba de juego.
- **Ediciones 26.3 y 1.21.11, cambios locales previos, tags y releases intactos.** Paquete local en Descargas, sin commit, push o publicación. No se afirman mejoras de FPS.
